# How Is My Wolf

A client-side Fabric mod that shows a panel beside your tamed wolves with their
name, owner, health, armor and state.

I made this mod because I wanted a fabric equivalent for
[YourDogStats](https://modrinth.com/mod/your-dog-stats) but I couldn't find
anything that was like it. So I built this mod from scratch to give me details
on my wolfies.

## Features

- Panel anchored to the wolf, with hearts, armor durability and
  sitting/following/angry state
- Vanilla tooltip style, or a border that matches the wolf's collar color
- Configurable via Mod Menu (toggle each row, linger time, panel distance)

## Requirements

- Minecraft 26.3, Fabric Loader, Fabric API, Cloth Config
- Mod Menu (optional, for the in-game config screen)

Works on any server, since it only reads what the client already sees.
